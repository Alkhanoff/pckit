# 3. Oyunun vizual forması

Oyun tam 3D engine ilə hazırlanmayacaq.

Oyun yüksək keyfiyyətli, həcm hissi verən **2.5D satisfying mobile game** kimi hazırlanmalıdır.

Məhsullar və materiallar aşağıdakılar vasitəsilə həcmli görünməlidir:

* perspektiv;
* yumşaq kölgələr;
* gradientlər;
* işıq əksləri;
* şəffaflıq;
* layer-lər;
* maskalar;
* deformasiya animasiyaları;
* parıltı;
* procedural qırışlar;
* touch hərəkətinə uyğun vizual reaksiya.

Oyun ucuz və statik 2D mobil tətbiq kimi görünməməlidir.

Texniki realizmdən daha vacib olan bunlardır:

* dərhal vizual cavab;
* axıcı animasiya;
* materialın hiss olunması;
* məhsulun həcmli görünməsi;
* səs, animasiya və haptic sinxronluğu.

## Vizual stil

* minimal;
* premium;
* yumşaq low-poly təsiri;
* təmiz və rahat rənglər;
* həddindən artıq parlaq olmayan UI;
* məhsulu ön plana çıxaran sadə fon;
* yaxın planda detallı material effektləri.

## Kamera

Gameplay sahəsi təxminən 35–45 dərəcə yuxarıdan görünməlidir.

Əsas kamera sabit olmalıdır.

Kəsmə, yapışdırma, möhür və qüsur düzəltmə zamanı avtomatik yaxınlaşma animasiyaları istifadə edilə bilər.

Oyunçu kameranı sərbəst fırlatmamalıdır.

# 6. Əsas oyun dövrəsi

Bir sifarişin gameplay dövrəsi belə olmalıdır:

1. Müştəri sifarişi göstərilir.
2. Məhsul qablaşdırma masasına gəlir.
3. Oyunçu qablaşdırma materialını seçir.
4. Məhsul və material gameplay səhnəsində göstərilir.
5. Oyunçu materialı toxunma hərəkətləri ilə idarə edir.
6. Məhsul qablaşdırılır.
7. Qüsurlar aşkar edilir.
8. Oyunçu qüsurları düzəldir.
9. Məhsul üç meyar üzrə qiymətləndirilir.
10. Oyunçu coin və reputasiya qazanır.
11. Növbəti sifarişə keçir.

Bir məhsulun qablaşdırılması təxminən 30–60 saniyə çəkməlidir.

Əsas Orders rejimində məcburi vaxt limiti olmamalıdır.

# 9. MVP qablaşdırma materialları

## 9.1 Streç film

Oyunçu:

1. Filmin ucuna toxunur.
2. Filmi rulondan çəkir.
3. Film drag məsafəsinə görə dartılır.
4. Məhsulun ətrafına dolanır.
5. Məhsul müəyyən mərhələlərdə avtomatik fırlanır.
6. Film kəsilir.
7. Film ucu məhsula yapışdırılır.
8. Qırış və hava qabarcıqları düzəldilir.

### Streç film texnologiyası

Real cloth simulation istifadə etmə.

Film aşağıdakılarla yaradılsın:

* şəffaf Skia layer;
* progressive coverage mask;
* məhsul səthlərinə uyğun clip mask;
* drag məsafəsinə bağlı stretch transform;
* opacity;
* gradient;
* specular highlight;
* procedural wrinkle path-ləri;
* film qatlarına bağlı şəffaflıq;
* hava qabarcığı üçün radial vizual effekt.

Məhsul wrap zonalarına bölünsün:

* front;
* back;
* left;
* right;
* top;
* bottom.

Oyunçu uyğun gesture etdikcə zonalar mərhələli şəkildə film ilə örtülsün.

### Dartılma vəziyyətləri

#### Loose

* film boş görünür;
* qırış ehtimalı artır;
* material istifadəsi yüksəlir;
* scoring azalır.

#### Optimal

* film hamar görünür;
* ən yaxşı nəticə verir;
* selection haptic işə düşür.

#### Overstretched

* film həddindən artıq dartılır;
* yumşaq qırmızı xəbərdarlıq göstərilir;
* warning haptic verilir;
* ilk MVP-də film dərhal cırılmır.

## 9.2 Bubble wrap

Oyunçu:

1. Bubble wrap materialını masaya sərir.
2. Məhsulu ortasına yerləşdirir.
3. Sol və sağ tərəfləri qatlayır.
4. Üst və alt hissələri bağlayır.
5. Lent çəkir.
6. İstəyə görə 2–3 qabarcıq partladır.

### Bubble wrap texnologiyası

* təkrarlanan dairə pattern-i;
* şəffaf layer;
* qatlama zonaları;
* clip mask;
* fold transform;
* interaktiv bubble nöqtələri.

Bubble partladıqda:

* qısa scale animasiyası;
* circle deformation;
* pop səsi;
* light haptic.

Tam fiziki material simulyasiyası yaratma.

## 9.3 Alüminium folqa

Oyunçu:

1. Folqanı rulondan açır.
2. Məhsulun üzərinə çəkir.
3. Kənarları sıxır.
4. Qırışları hamarlayır.
5. Artıq hissəni kəsir.

### Folqa texnologiyası

* metalik gradient;
* noise texture;
* highlight;
* procedural wrinkle path-ləri;
* pressure əsaslı wrinkle dəyişməsi;
* məhsula uyğun mask;
* kənar qatlama animasiyaları.

Oyunçu qırışı hamarladıqca:

* wrinkle amplitude azalsın;
* opacity azalsın;
* folqa daha təmiz görünsün.

## 9.4 Premium hədiyyə kağızı

Oyunçu:

1. Kağız ölçüsünü seçir.
2. Qutunu kağızın ortasına yerləşdirir.
3. Uzun tərəfləri qatlayır.
4. Küncləri içəri qatlayır.
5. Kağızı yapışdırır.
6. Dekorativ lent əlavə edir.
7. Möhür vurur.

### Kağız texnologiyası

* kağız pattern-i;
* qatlama zonaları;
* mərhələli transform;
* künc fold-ları;
* lent layer-i;
* möhür layer-i;
* simmetriya scoring-i.

# 11. Gesture sistemi

İstifadə et:

* React Native Gesture Handler;
* React Native Reanimated.

Dəstəklənən gesture-lər:

* Tap
* Pan
* Drag
* Swipe
* Hold
* Release

Gesture-lər gameplay komponentlərinin daxilində qarışıq şəkildə yazılmamalıdır.

Ayrıca gesture və interaction sistemi qur.

Gesture hesablamalarını mümkün qədər UI thread-də Reanimated worklet-lərlə apar.

Gesture zamanı hər frame React state update etmə.

Real-time məlumatlar üçün istifadə et:

* shared values;
* derived values;
* animated props;
* animated styles.

React və Zustand state yalnız bunlar üçün istifadə edilsin:

* gameplay mərhələsi;
* sifariş;
* məhsul;
* material;
* scoring;
* nəticə;
* daimi progress.

Real-time gesture koordinatlarını Zustand daxilində saxlama.

* pulling

* repairing mərhələsinə keçmədən qüsur düzəltmək aktiv olmamalıdır.

# 13. Qüsur və düzəltmə sistemi

MVP-də aşağıdakı qüsurlar olsun:

* qırış;
* hava qabarcığı;
* açıq qalan künc;
* boş material ucu;
* artıq material;
* əyri lent;
* əyri möhür və ya etiket.

Qüsurlar mümkün qədər oyunçunun hərəkətindən yaranmalıdır.

Nümunələr:

* zəif dartılma → qırış;
* qeyri-bərabər drag → açıq künc;
* artıq material → aşağı efficiency;
* yanlış sealing → boş film ucu;
* qeyri-bərabər hamarlama → hava qabarcığı;
* qeyri-simmetrik yerləşdirmə → əyri möhür.

Təsadüfi qüsurları minimum istifadə et.

Oyunçu qüsurun niyə yarandığını başa düşməlidir.

## Düzəltmə hərəkətləri

* qırış üzərində swipe;
* hava qabarcığını kənara drag;
* açıq küncə material çəkmək;
* boş material ucunu sıxmaq;
* artıq materialı kəsmək;
* əyri etiketi götürüb yenidən yerləşdirmək;
* möhürü düz mövqeyə çəkmək.

Qüsurlar cəza yox, əlavə satisfying mini-game kimi hiss edilməlidir.

Oyunçu səhvə görə sifarişi tam itirməməlidir.
