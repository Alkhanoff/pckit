# PACK & RELAX
## Aydın Development Mərhələləri və İcra Ardıcıllığı

# 1. Əsas icra qaydası

Layihəni aşağıdakı mərhələlər üzrə ardıcıl qur.

Bütün oyunu bir dəfəyə hazırlama. Əvvəlcə bir məhsul və bir material ilə tam işlək **vertical slice** yarat, daha sonra həmin stabil sistemin üzərinə yeni materiallar və məhsullar əlavə et.

Hər mərhələdə bu ardıcıllığa əməl et:

1. Mövcud repository və kodu analiz et.
2. Həmin mərhələnin fayllarını və tapşırıqlarını müəyyən et.
3. Kod və konfiqurasiyanı birbaşa layihəyə tətbiq et.
4. TypeScript typecheck, lint və avtomatik testləri işə sal.
5. Web preview və uyğun olduqda mobil preview build yoxlaması apar.
6. Aşkarlanan error-ları özün düzəlt.
7. Acceptance kriteriyalarını yoxla.
8. Dəyişiklikləri Git commit et.
9. Bütün kriteriyalar keçərsə avtomatik növbəti mərhələyə keç.

İstifadəçidən texniki kod yazmağı, terminal əmri işlətməyi, dependency quraşdırmağı və ya config dəyişməyi istəmə.

Yalnız aşağıdakı qaçılmaz hallarda istifadəçi müdaxiləsi tələb et:

- Expo, GitHub, Apple və Google hesablarına giriş;
- iki mərhələli təsdiq;
- developer hesablarının yaradılması və ödənişi;
- hüquqi müqavilələrin qəbul edilməsi;
- credential və API key daxil edilməsi;
- hazır build-in fiziki telefonda vizual və toxunma testi.

# Mərhələ 6 — Streç filmi tutmaq və dartmaq

## Məqsəd

Oyunçunun filmin ucunu tutaraq rulondan çəkməsini və gərginliyi hiss etməsini təmin etmək.

## Oyun axını

1. Oyunçu filmin ucuna toxunur.
2. Film seçilir və light haptic verilir.
3. Oyunçu filmi məhsula doğru çəkir.
4. Film drag məsafəsinə uyğun uzanır.
5. Tension göstəricisi dəyişir.

## Tension vəziyyətləri

### Loose

- Film boş və daha qırışlı görünür.
- Material istifadəsi artır.

### Optimal

- Film hamar və parlaq görünür.
- Selection haptic verilir.
- Scoring üçün ideal intervaldır.

### Overstretched

- Yumşaq qırmızı xəbərdarlıq görünür.
- Warning haptic verilir.
- Film ilk MVP-də cırılmır.

## Texniki yanaşma

- Şəffaf Skia layer;
- gradient;
- opacity;
- stretch transform;
- specular highlight;
- procedural qırış path-ləri.

## Keçid qapısı

- [ ] Film rulondan vizual olaraq çıxır.
- [ ] Drag məsafəsi film uzunluğuna təsir edir.
- [ ] Üç tension vəziyyəti aydın fərqlənir.
- [ ] Gesture buraxıldıqda state düzgün saxlanılır və ya geri qayıdır.
- [ ] Audio və haptic üçün event-lər mövcuddur.
